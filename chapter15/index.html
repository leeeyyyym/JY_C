    최종 완성 & 다음 여정 — MBTI 게임 총정리¶

    🎯 이 장에서 배우는 것¶

    • 완성된 MBTI 게임 코드에서 변수, 조건문, 반복문, 함수, 배열, 구조체가 어디에 쓰였는지 식별할 수 있다
    • 전체 코드를 직접 실행하고 나만의 MBTI 결과를 확인할 수 있다
    • C언어 기초에서 아두이노·IoT로 이어지는 학습 경로를 설명할 수 있다

    📚 핵심 개념¶

    개념: 코드 리뷰 — 전체를 한눈에 보기¶

    1. 비유로 시작: "코드 리뷰는 마치 완성된 레고 작품을 돌려보며 '이 블록이 기둥이고, 이게 지붕이구나'라고 확인하는 것과 같아요."

    2. 정확한 정의: 코드 리뷰란 완성된 프로그램을 처음부터 끝까지 읽으며, 각 부분이 어떤 역할을 하고 어떤 개념이 적용되었는지 파악하는 활동입니다.

    3. 우리 게임에 사용된 개념 한눈에 보기:

    graph LR A["🧱 구조체"] --> B["질문 데이터 묶기"] C["📦 배열"] --> D["질문 8개 저장"] E["🔁 반복문"] --> F["질문 순회 출력"] G["❓ 조건문"] --> H["점수→MBTI 판정"] I["⚙️ 함수"] --> J["기능별 분리"] K["📝 변수"] --> L["점수 누적 저장"]

    🔨 따라하기¶

    Step 1: 전체 코드 훑어보며 개념 찾기¶

    아래 전체 코드를 읽으면서, 주석에 표시된 개념 태그를 확인해보세요. "아, 여기서 그걸 배웠지!" 하는 순간이 올 거예요 😊

    Step 2: 직접 실행하고 나만의 결과 확인하기¶

    코드를 복사해서 실행한 뒤, 솔직하게 답해보세요. 친구와 서로 테스트해봐도 재미있어요!

    📝 전체 코드¶

    #include <stdio.h>

/* ── [구조체] 질문 데이터를 하나로 묶기 ── */
typedef struct {
    char question[100];
    int dimension; // 0:EI  1:SN  2:TF  3:JP
} Question;

/* ── [함수] MBTI 결과 판정 ── */
void printResult(int scores[]) {
    char mbti[5];

    /* ── [조건문] 점수에 따라 글자 결정 ── */
    mbti[0] = (scores[0] >= 2) ? 'E' : 'I';
    mbti[1] = (scores[1] >= 2) ? 'S' : 'N';
    mbti[2] = (scores[2] >= 2) ? 'T' : 'F';
    mbti[3] = (scores[3] >= 2) ? 'J' : 'P';
    mbti[4] = '\0';

    printf("\n🎉 당신의 MBTI는: %s\n", mbti);
}

int main(void) {
    /* ── [배열 + 구조체] 질문 8개 저장 ── */
    Question quiz[8] = {
        {"모임에서 먼저 말을 거는 편이다? (1:예 0:아니오)", 0},
        {"사람 많은 곳에서 에너지를 얻는다? (1:예 0:아니오)", 0},
        {"구체적인 사실에 집중하는 편이다? (1:예 0:아니오)", 1},
        {"경험을 통해 배우는 걸 선호한다? (1:예 0:아니오)", 1},
        {"결정할 때 논리를 우선한다? (1:예 0:아니오)", 2},
        {"공정함이 배려보다 중요하다? (1:예 0:아니오)", 2},
        {"계획을 세우고 실행하는 편이다? (1:예 0:아니오)", 3},
        {"마감 전에 미리 끝내는 걸 좋아한다? (1:예 0:아니오)", 3}
    };

    /* ── [변수] 4가지 차원 점수 ── */
    int scores[4] = {0, 0, 0, 0};
    int answer;

    printf("=== 🧠 나만의 MBTI 테스트 ===\n\n");

    /* ── [반복문] 질문 순회 ── */
    for (int i = 0; i < 8; i++) {
        printf("Q%d. %s\n>> ", i + 1, quiz[i].question);
        scanf("%d", &answer);

        if (answer == 1) {
            scores[quiz[i].dimension]++;
        }
    }

    /* ── [함수 호출] 결과 출력 ── */
    printResult(scores);

    return 0;
}

    ⚠️ 주의할 점¶

    1. scanf에 문자를 입력하면 무한 루프에 빠질 수 있어요. 반드시 숫자 0 또는 1만 입력하세요!
    2. 질문을 추가하고 싶다면, 배열 크기와 for문의 반복 횟수를 함께 바꿔야 합니다.

    ✅ 점검하기¶

    1. quiz[8]에서 배열과 구조체가 동시에 사용된 이유는 무엇일까요?
    정답 확인각 질문은 "질문 텍스트"와 "차원 번호"라는 서로 다른 타입의 데이터를 함께 가지므로 구조체로 묶고, 질문이 여러 개이므로 배열로 나열한 것입니다.
    1. scores[quiz[i].dimension]++에서 어떤 개념이 몇 가지 사용되었나요?
    정답 확인배열(scores), 구조체 멤버 접근(quiz[i].dimension), 반복문 변수(i), 증감 연산자(++) — 총 4가지 개념이 한 줄에 담겨 있습니다!
    1. 이 프로그램에서 printResult를 함수로 분리한 이점은?
    정답 확인main 함수가 깔끔해지고, 결과 출력 로직만 따로 수정·재사용할 수 있습니다.
