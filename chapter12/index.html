    구조체 (2) — 구조체와 함수를 연결하자¶

    🎯 이 장에서 배우는 것¶

    • 구조체를 함수의 매개변수로 전달하고, 반환값으로 받을 수 있다
    • 구조체 배열로 여러 사람의 데이터를 한꺼번에 관리할 수 있다
    • 구조체와 함수를 연결하여 MBTI 게임 코드를 깔끔하게 완성할 수 있다

    📚 핵심 개념¶

    개념: 구조체를 함수에 전달하기¶

    비유로 시작 🚚

    택배를 보낸다고 생각해보세요. 이름, 점수, 결과를 하나씩 따로따로 보내면 번거롭죠? 구조체는 이 모든 걸 하나의 박스에 담아 한 번에 보내는 것과 같아요. 함수에 구조체를 넘기면, 여러 데이터를 깔끔하게 전달할 수 있습니다.

    정확한 정의

    구조체 변수를 함수의 매개변수로 넘기는 방법은 크게 두 가지입니다.

    • 값 전달: 구조체를 복사해서 넘김 → 원본이 바뀌지 않음
    • 포인터 전달: 구조체의 주소를 넘김 → 함수 안에서 원본을 직접 수정 가능

    포인터로 넘길 때는 . 대신 -> (화살표 연산자)를 씁니다.

    void greet(Player *p) {
    printf("안녕, %s!\n", p->name);  // 포인터니까 -> 사용
}
    flowchart LR A["main()에서\nPlayer p 생성"] -->|"&p (주소 전달)"| B["greet(Player *p)\np->name 접근"] B -->|"원본 직접 수정 가능"| A

    💡 왜 포인터로 넘길까? 구조체는 데이터가 많아서 통째로 복사하면 느려요. 주소만 넘기면 빠르고, 함수 안에서 값도 바꿀 수 있어 일석이조!

    🔨 따라하기¶

    Step 1: 구조체를 함수에 넘겨보기¶

    질문을 묻고 점수를 기록하는 함수를 만들어봅시다.

    #include <stdio.h>

typedef struct {
    char name[20];
    int e_score;  // E 성향 점수
} Player;

// 구조체 포인터를 받아 질문하고 점수를 기록하는 함수
void ask_question(Player *p) {
    int answer;
    printf("[%s] 파티에 가면 신나나요? (1:예 2:아니오): ", p->name);
    scanf("%d", &answer);
    if (answer == 1) {
        p->e_score++;  // 원본의 점수가 직접 올라감!
    }
}

int main(void) {
    Player p1 = {"민수", 0};

    ask_question(&p1);  // 주소를 넘긴다

    printf("%s의 E점수: %d\n", p1.name, p1.e_score);
    return 0;
}

    실행 결과: 

    [민수] 파티에 가면 신나나요? (1:예 2:아니오): 1
민수의 E점수: 1

    핵심은 &p1으로 주소를 넘기고, 함수 안에서 p->e_score++로 원본을 직접 수정한다는 점이에요.

    Step 2: 구조체 배열로 친구 3명 결과 저장하기¶

    Player players[3]으로 여러 명의 데이터를 관리해봅시다.

    #include <stdio.h>

typedef struct {
    char name[20];
    int e_score;
} Player;

void ask_question(Player *p) {
    int answer;
    printf("[%s] 파티에 가면 신나나요? (1:예 2:아니오): ", p->name);
    scanf("%d", &answer);
    if (answer == 1) p->e_score++;
}

// 결과를 판정해서 출력하는 함수
void show_result(Player *p) {
    if (p->e_score >= 1)
        printf("  %s → E (외향형) 🎉\n", p->name);
    else
        printf("  %s → I (내향형) 📚\n", p->name);
}

int main(void) {
    Player players[3] = {
        {"민수", 0}, {"지은", 0}, {"하준", 0}
    };

    for (int i = 0; i < 3; i++) {
        ask_question(&players[i]);  // 각 플레이어 주소를 넘김
    }

    printf("\n=== 결과 발표 ===\n");
    for (int i = 0; i < 3; i++) {
        show_result(&players[i]);
    }
    return 0;
}

    실행 결과: 

    [민수] 파티에 가면 신나나요? (1:예 2:아니오): 1
[지은] 파티에 가면 신나나요? (1:예 2:아니오): 2
[하준] 파티에 가면 신나나요? (1:예 2:아니오): 1

=== 결과 발표 ===
  민수 → E (외향형) 🎉
  지은 → I (내향형) 📚
  하준 → E (외향형) 🎉

    for문과 구조체 배열이 만나니, 3명이든 100명이든 같은 코드로 처리할 수 있어요!

    📝 전체 코드¶

    위 Step 2의 코드가 이 챕터의 최종 완성 코드입니다. 복사해서 바로 실행해보세요.

    ⚠️ 주의할 점¶

    1. .과 -> 헷갈리지 않기! — 일반 변수는 p1.name, 포인터는 p->name. 이것만 기억하세요.
    2. &를 빼먹지 마세요 — ask_question(players[i])가 아니라 ask_question(&players[i])입니다. 주소를 넘겨야 원본이 바뀝니다.

    ✅ 점검하기¶

    1. 구조체를 함수에 넘길 때 포인터를 사용하는 이유 두 가지는?

    정답 확인 ① 구조체 전체를 복사하지 않아 효율적이다. ② 함수 안에서 원본 데이터를 직접 수정할 수 있다.

    2. 포인터로 받은 구조체의 멤버에 접근할 때 사용하는 연산자는?

    정답 확인 -> (화살표 연산자). 예: p->name, p->e_score

    3. Player players[3]에서 두 번째 플레이어의 주소를 함수에 넘기려면?

    정답 확인 &players[1] (배열 인덱스는 0부터 시작하므로 두 번째는 1)
