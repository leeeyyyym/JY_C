    입출력 — MBTI 게임의 첫 화면 만들기¶

    🎯 이 장에서 배우는 것¶

    • printf의 서식 지정자(%d, %s, %f)를 활용하여 다양한 데이터를 출력할 수 있다
    • scanf를 사용하여 사용자로부터 데이터를 입력받을 수 있다
    • printf와 scanf를 조합하여 MBTI 게임의 인트로 화면을 완성할 수 있다

    📚 핵심 개념¶

    개념 1: printf — 빈칸 채우기 출력 🖨️¶

    비유로 시작: printf는 마치 빈칸이 있는 편지 템플릿과 같아요.

    "안녕하세요, _님! 당신의 나이는 _세입니다."

    이 빈칸에 이름과 나이를 끼워 넣는 것이 바로 printf의 서식 지정자입니다.

    정확한 정의: printf는 서식 문자열(format string) 안에 % 기호로 시작하는 빈칸을 두고, 뒤에 오는 값으로 채워서 출력하는 함수입니다.

    파이썬과 비교해볼까요?

    # 파이썬의 f-string
name = "철수"
age = 20
print(f"안녕, {name}! 나이: {age}세")

    // C언어의 printf
char name[] = "철수";
int age = 20;
printf("안녕, %s! 나이: %d세\n", name, age);

    파이썬은 {변수명}으로 빈칸을 표현하지만, C언어는 데이터 타입에 맞는 서식 지정자를 써야 합니다.

    자주 쓰는 서식 지정자 3총사 🎯

    • %d → 정수 (decimal) : int age = 20; → printf("%d", age); → 20
    • %s → 문자열 (string) : char name[] = "철수"; → printf("%s", name); → 철수
    • %f → 실수 (float) : float score = 3.14; → printf("%f", score); → 3.140000

    💡 팁: %f는 기본적으로 소수점 6자리까지 출력해요. %.1f처럼 쓰면 소수점 1자리만 나옵니다!

    개념 2: scanf — 사용자에게 값 받기 📮¶

    비유로 시작: scanf는 마치 택배 주문과 같아요. 택배를 받으려면 반드시 배송 주소를 알려줘야 하죠? scanf에게도 "이 값을 어디에 저장할지" 주소를 알려줘야 합니다.

    int age;
scanf("%d", &age);  // &age = "age 변수의 주소"

    여기서 &가 바로 "이 변수의 주소"라는 뜻입니다.

    flowchart LR A["사용자 입력: 25"] -->|"scanf가 받아서"| B["&age 주소로 배달"] B --> C["age 변수에 25 저장 📦"]

    ⚠️ &를 빼먹으면? 택배 주소 없이 택배를 보내는 것과 같아서, 프로그램이 오류를 일으킵니다. (단, 문자열(%s)일 때는 배열 이름 자체가 주소라서 &를 안 붙여요. 이유는 7차시 포인터에서 자세히!)

    파이썬과 비교:

    # 파이썬 — 간단!
age = int(input("나이: "))

    // C언어 — 타입과 주소를 명시!
int age;
printf("나이: ");
scanf("%d", &age);

    C언어가 좀 더 번거롭지만, 그만큼 컴퓨터에게 정확한 지시를 내리는 셈이에요.

    🔨 따라하기: MBTI 게임 인트로 만들기¶

    Step 1: 환영 메시지 출력하기¶

    먼저 게임 제목을 출력해봅시다.

    #include <stdio.h>

int main(void) {
    printf("=============================\n");
    printf("   나만의 MBTI 테스트 게임\n");
    printf("=============================\n");
    return 0;
}

    실행 결과: 

    =============================
   나만의 MBTI 테스트 게임
=============================

    Step 2: 이름 입력받기¶

    사용자의 이름을 받아봅시다.

    #include <stdio.h>

int main(void) {
    char name[50];  // 이름을 저장할 공간 (최대 49글자)

    printf("플레이어 이름을 입력하세요: ");
    scanf("%s", name);  // 문자열이라 & 안 붙임!

    printf("환영합니다, %s님!\n", name);
    return 0;
}

    실행 결과: 

    플레이어 이름을 입력하세요: 민수
환영합니다, 민수님!

    Step 3: 나이도 입력받기¶

    서식 지정자 %d를 활용해 나이도 받아봅시다.

    #include <stdio.h>

int main(void) {
    char name[50];
    int age;

    printf("이름을 입력하세요: ");
    scanf("%s", name);

    printf("나이를 입력하세요: ");
    scanf("%d", &age);  // 정수라 & 필요!

    printf("%s님(%d세), 게임을 시작합니다!\n", name, age);
    return 0;
}

    실행 결과: 

    이름을 입력하세요: 지은
나이를 입력하세요: 23
지은님(23세), 게임을 시작합니다!

    Step 4: 인트로 화면 완성! 🎮¶

    모든 것을 합쳐서 멋진 인트로를 만들어봅시다.

    📝 전체 코드¶

    #include <stdio.h>

int main(void) {
    char name[50];
    int age;

    // 게임 타이틀
    printf("=============================\n");
    printf("   나만의 MBTI 테스트 게임\n");
    printf("=============================\n\n");

    // 플레이어 정보 입력
    printf("플레이어 이름을 입력하세요: ");
    scanf("%s", name);

    printf("나이를 입력하세요: ");
    scanf("%d", &age);

    // 환영 메시지 출력
    printf("\n-----------------------------\n");
    printf("환영합니다, %s님! (%d세)\n", name, age);
    printf("지금부터 MBTI 테스트를 시작합니다.\n");
    printf("-----------------------------\n");

    return 0;
}

    실행 결과: 

    =============================
   나만의 MBTI 테스트 게임
=============================

플레이어 이름을 입력하세요: 하준
나이를 입력하세요: 21

-----------------------------
환영합니다, 하준님! (21세)
지금부터 MBTI 테스트를 시작합니다.
-----------------------------

    ⚠️ 주의할 점¶

    1. scanf에서 & 빼먹지 않기!

    %d, %f로 입력받을 때는 반드시 변수 앞에 &를 붙이세요. 빼먹으면 프로그램이 비정상 종료될 수 있습니다. 단, %s(문자열)는 예외로 &를 붙이지 않습니다.

    2. scanf의 %s는 공백 전까지만 읽어요!

    "홍 길동"처럼 이름에 공백이 있으면 "홍"만 저장됩니다. 공백 포함 입력은 나중에 fgets 함수로 해결할 수 있어요. 지금은 공백 없는 이름으로 테스트하세요! 😊

    ✅ 점검하기¶

    1. 다음 코드의 출력 결과는 무엇일까요? 

    int x = 10;
float y = 3.5;
printf("정수: %d, 실수: %.1f", x, y);

    정답 확인 `정수: 10, 실수: 3.5` `%d`는 정수 10을, `%.1f`는 실수 3.5를 소수점 1자리까지 출력합니다.

    2. scanf로 정수를 입력받을 때 &를 붙여야 하는 이유는?

    정답 확인 scanf는 입력받은 값을 변수에 저장해야 하는데, 그러려면 **변수의 메모리 주소**를 알아야 합니다. `&`는 "이 변수의 주소"를 알려주는 연산자입니다. 택배를 받으려면 배송 주소가 필요한 것과 같은 원리예요!

    3. 문자열을 scanf로 입력받을 때 &를 안 붙이는 이유는?

    정답 확인 `char name[50]`처럼 선언한 배열의 이름(`name`)은 그 자체가 배열의 시작 주소를 나타내기 때문입니다. 이미 주소이므로 `&`를 또 붙일 필요가 없어요. 자세한 원리는 7차시 포인터에서 배웁니다!
