    포인터 맛보기 — 주소의 세계 엿보기¶

    🎯 이 장에서 배우는 것¶

    • &(주소 연산자)와 *(역참조 연산자)의 의미를 비유를 통해 이해할 수 있다
    • 변수의 메모리 주소를 출력하고, 포인터 변수에 저장하는 코드를 작성할 수 있다
    • scanf에서 &를 써왔던 이유를 포인터 개념으로 설명할 수 있다

    📚 핵심 개념¶

    개념 1: & — 주소 연산자 (이 변수 어디 살아?)¶

    비유로 시작 🏠

    변수는 아파트 한 칸이에요. 그 안에 값(주민)이 살고 있죠. &는 그 아파트의 동·호수(주소)를 알려주는 연산자입니다.

    int score = 95;라고 선언하면, 컴퓨터 메모리 어딘가에 95가 저장됩니다. 우리 눈에는 score라는 이름만 보이지만, 실제로 그 칸에는 고유한 주소 번호가 있어요.

    • score → 그 칸에 들어있는 값 (95)
    • &score → 그 칸의 주소 (예: 0x7ffd5e8a)

    정의: &변수이름은 해당 변수가 저장된 메모리 주소를 돌려줍니다.

    💡 사실 여러분은 이미 &를 써왔어요!

    scanf("%d", &score);  // score의 "주소"를 scanf에게 알려준 것!

    scanf는 키보드 입력값을 어디에 넣어야 하는지 알아야 합니다. 그래서 값이 아니라 주소를 전달한 거예요. "이 주소로 가서 값을 넣어줘!"라고 말한 셈이죠.

    개념 2: * — 역참조 연산자 (그 주소에 가보자!)¶

    비유 이어가기 📬

    친구에게 메모지를 받았어요. 거기엔 주소가 적혀 있습니다. 그 주소로 직접 찾아가서 안에 뭐가 있는지 확인하는 것이 *입니다.

    포인터 변수는 바로 이 "주소가 적힌 메모지"예요.

    int score = 95;
int *ptr = &score;  // ptr이라는 메모지에 score의 주소를 적음
    • ptr → 주소값 자체 (예: 0x7ffd5e8a)
    • *ptr → 그 주소에 찾아가서 읽은 값 (95)

    정의: *포인터변수는 포인터가 가리키는 주소로 가서 그곳의 값을 읽거나 씁니다.

    flowchart LR A["변수 score\n값: 95\n주소: 0x7ffd5e8a"] --- B["포인터 ptr\n값: 0x7ffd5e8a"] B -- "*ptr로 접근" --> A A -- "&score로 주소 획득" --> B

    정리하면 — &는 "주소 알려줘", *는 "그 주소로 가줘" 🚀

    🔨 따라하기¶

    Step 1: 변수의 주소 출력해보기¶

    #include <stdio.h>

int main(void) {
    int score = 95;

    printf("값  : %d\n", score);
    printf("주소: %p\n", &score);  // %p는 주소 출력 서식

    return 0;
}

    실행 결과 (주소는 매번 달라요!): 

    값  : 95
주소: 0x7ffd5e8a3b4c

    %p는 주소를 16진수로 출력하는 서식 문자입니다. 숫자가 길고 이상해 보여도 정상이에요! 😊

    Step 2: 포인터 변수 선언과 역참조¶

    #include <stdio.h>

int main(void) {
    int score = 95;
    int *ptr = &score;  // 포인터 변수 선언 + 주소 저장

    printf("score의 값      : %d\n", score);
    printf("ptr에 저장된 주소: %p\n", ptr);
    printf("*ptr로 읽은 값   : %d\n", *ptr);  // 역참조!

    return 0;
}

    실행 결과: 

    score의 값      : 95
ptr에 저장된 주소: 0x7ffd5e8a3b4c
*ptr로 읽은 값   : 95

    score를 직접 읽든, *ptr로 읽든 같은 값이 나옵니다. 같은 집을 이름으로 부르느냐, 주소로 찾아가느냐의 차이일 뿐!

    Step 3: 포인터로 값 바꾸기¶

    #include <stdio.h>

int main(void) {
    int score = 95;
    int *ptr = &score;

    printf("변경 전: %d\n", score);

    *ptr = 100;  // 주소로 찾아가서 값을 변경!

    printf("변경 후: %d\n", score);  // score가 바뀌었다!

    return 0;
}

    실행 결과: 

    변경 전: 95
변경 후: 100

    *ptr = 100은 "ptr이 가리키는 주소로 가서 100을 넣어라"는 뜻이에요. 그래서 score 자체가 바뀝니다. scanf가 했던 일이 바로 이거예요! 📮

    Step 4: scanf의 비밀, 드디어 해명!¶

    #include <stdio.h>

int main(void) {
    int age;

    printf("나이 입력: ");
    scanf("%d", &age);  // age의 주소를 넘겨줌

    // scanf 내부에서는 이런 일이 일어난 것:
    // int *내부포인터 = &age;
    // *내부포인터 = 입력값;

    printf("입력한 나이: %d\n", age);

    return 0;
}

    scanf는 우리가 넘긴 주소를 통해 직접 age의 값을 채워넣습니다. 만약 & 없이 scanf("%d", age)로 쓰면? scanf는 엉뚱한 곳에 값을 쓰려다 오류가 나요. 1차시부터 &를 붙였던 이유가 바로 포인터였습니다! 🎉

    📝 전체 코드¶

    #include <stdio.h>

int main(void) {
    // 1. 변수 선언
    int score = 95;

    // 2. 포인터 변수에 주소 저장
    int *ptr = &score;

    // 3. 다양한 방법으로 확인
    printf("=== 포인터 맛보기 ===\n");
    printf("score 값       : %d\n", score);
    printf("score 주소(&)  : %p\n", &score);
    printf("ptr 저장 주소  : %p\n", ptr);
    printf("*ptr 역참조    : %d\n", *ptr);

    // 4. 포인터로 값 변경
    *ptr = 100;
    printf("\n*ptr = 100 실행 후\n");
    printf("score 값       : %d\n", score);

    return 0;
}

    ⚠️ 주의할 점¶

    • 선언할 때 *와 사용할 때 *는 의미가 다릅니다
    • int *ptr → "ptr은 포인터 변수입니다" (선언)
    • *ptr = 100 → "ptr이 가리키는 곳의 값" (역참조)

    • 같은 기호지만 문맥이 다르니 헷갈리지 마세요!

    • 포인터는 지금 완벽히 이해하지 않아도 괜찮아요 🙆

    • 이 챕터는 "맛보기"입니다. C 언어를 더 배우면서 자연스럽게 익숙해져요
    • 아두이노에서 하드웨어 레지스터 주소를 직접 다룰 때 포인터가 빛을 발합니다!

    ✅ 점검하기¶

    1. int num = 42;일 때, &num은 무엇을 의미하나요?

    정답 확인 변수 `num`이 저장된 **메모리 주소**를 의미합니다. `&`는 주소 연산자로, 변수의 위치(주소)를 알려줍니다.

    2. int *ptr = &num;으로 선언한 뒤, *ptr의 값은?

    정답 확인 `42`입니다. `*ptr`은 역참조 연산자로, `ptr`이 가리키는 주소(= `num`의 주소)로 가서 그곳의 값을 읽습니다.

    3. scanf("%d", &age);에서 &를 빼면 어떻게 되나요? 그 이유는?

    정답 확인 오류가 발생합니다. `scanf`는 입력값을 저장할 **주소**가 필요한데, `&` 없이 `age`만 전달하면 `age`의 **값**(초기화되지 않은 쓰레기값)을 주소로 착각하여 엉뚱한 곳에 쓰려고 시도하기 때문입니다.
