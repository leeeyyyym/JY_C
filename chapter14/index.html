    비트연산자 맛보기 — 컴퓨터가 진짜로 이해하는 언어¶

    🎯 이 장에서 배우는 것¶

    • 비트(bit)가 무엇인지, 8비트로 숫자를 표현하는 방식을 이해한다
    • AND(&), OR(|), 시프트(<<) 연산자의 동작을 코드로 확인할 수 있다
    • 비트연산이 실제로 어디에 쓰이는지 감을 잡는다

    📚 핵심 개념¶

    개념: 비트(bit)와 비트연산¶

    비유로 시작 💡

    벽에 전등 스위치 8개가 나란히 있다고 상상해보세요. 각 스위치는 켜짐(1) 또는 꺼짐(0) 두 가지 상태만 가능합니다. 이 스위치 하나하나가 바로 비트(bit) 입니다. 스위치 8개를 묶으면 1바이트(byte) — 0~255까지 256가지 상태를 표현할 수 있어요.

    정확한 정의

    비트연산자는 숫자를 2진수(0과 1의 나열)로 보고, 각 자리를 개별적으로 조작하는 연산자입니다.

    주요 연산자 3가지 🔧

    • & (AND): 둘 다 1일 때만 1 → 특정 비트가 켜져있는지 확인할 때
    • | (OR): 둘 중 하나라도 1이면 1 → 특정 비트를 켜줄 때
    • << (왼쪽 시프트): 비트를 왼쪽으로 밀기 → 원하는 자리를 지정할 때

    예시로 확인

    1 << 3은 숫자 1의 비트를 왼쪽으로 3칸 밀어서, 3번 자리에 1을 만듭니다.

    00000001  →  (3칸 이동)  →  00001000  = 8

    🔨 따라하기¶

    Step 1: 비트연산 기본 동작 확인¶

    #include <stdio.h>

int main(void) {
    unsigned char lights = 0;  // 스위치 8개 모두 OFF

    // 2번 스위치 켜기 (OR 사용)
    lights = lights | (1 << 2);
    printf("2번 ON: %d\n", lights);  // 4 (00000100)

    // 5번 스위치도 켜기
    lights = lights | (1 << 5);
    printf("5번도 ON: %d\n", lights);  // 36 (00100100)

    // 2번이 켜져있는지 확인 (AND 사용)
    if (lights & (1 << 2)) {
        printf("2번 스위치: 켜져있음!\n");
    }

    return 0;
}

    실행 결과: 

    2번 ON: 4
5번도 ON: 36
2번 스위치: 켜져있음!

    Step 2: MBTI를 4비트로 표현하기 🧬¶

    E/I, S/N, T/F, J/P — 각각 0 또는 1로 표현하면 4비트 하나로 MBTI 16가지를 담을 수 있습니다!

    #include <stdio.h>

int main(void) {
    // 규칙: E=0/I=1, S=0/N=1, T=0/F=1, J=0/P=1
    unsigned char mbti = 0;

    // INFP를 만들어보자!
    mbti = mbti | (1 << 3);  // I (3번 비트)
    mbti = mbti | (1 << 2);  // N (2번 비트)
    mbti = mbti | (1 << 1);  // F (1번 비트)
    mbti = mbti | (1 << 0);  // P (0번 비트)

    printf("INFP = %d (2진수: 1111)\n", mbti);  // 15

    // 이 사람이 I(내향)인지 확인
    if (mbti & (1 << 3)) {
        printf("내향형(I)입니다!\n");
    }

    return 0;
}

    실행 결과: 

    INFP = 15 (2진수: 1111)
내향형(I)입니다!

    🌟 왜 이게 유용할까? 아두이노에서 LED 8개를 제어하거나, 센서 상태를 확인할 때 바로 이 방식을 씁니다. 하드웨어 레지스터가 바로 이런 "스위치 모음"이거든요!

    📝 전체 코드¶

    #include <stdio.h>

int main(void) {
    // === 비트연산 기본 ===
    unsigned char lights = 0;
    lights = lights | (1 << 2);   // 2번 ON
    lights = lights | (1 << 5);   // 5번 ON
    printf("lights = %d\n", lights);

    if (lights & (1 << 2)) {
        printf("2번: ON\n");
    }

    // === MBTI 비트 플래그 ===
    unsigned char mbti = 0;
    mbti |= (1 << 3);  // I
    mbti |= (1 << 2);  // N
    mbti |= (1 << 1);  // F
    mbti |= (1 << 0);  // P
    printf("INFP = %d\n", mbti);

    return 0;
}

    ⚠️ 주의할 점¶

    1. &와 &&는 다릅니다! &는 비트 AND, &&는 논리 AND(조건문용). 헷갈리면 버그의 원인이 됩니다.
    2. 비트연산은 정수형에만 사용하세요. float이나 double에는 쓰지 않습니다.

    ✅ 점검하기¶

    1. 1 << 4의 결과는 10진수로 얼마일까요?

    정답 확인16입니다. 00000001이 왼쪽으로 4칸 이동하면 00010000 = 16

    2. lights | (1 << 3)은 어떤 역할을 하나요?

    정답 확인lights의 3번 비트를 1로 켜줍니다. 나머지 비트는 그대로 유지됩니다.

    3. 특정 비트가 켜져있는지 확인할 때 쓰는 연산자는?

    정답 확인AND 연산자(&)입니다. 예: if (value & (1 << n))으로 n번 비트를 확인합니다.
