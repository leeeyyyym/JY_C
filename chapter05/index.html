    반복문 — 질문을 여러 개 돌리자¶

    Part 2: 게임에 두뇌를 달자 — 조건문과 반복문

    🎯 이 장에서 배우는 것¶

    • for문과 while문의 구조를 이해하고 상황에 맞게 사용할 수 있다
    • 반복문 안에 조건문을 결합하여 점수를 누적하는 로직을 작성할 수 있다
    • MBTI 질문 여러 개를 반복문으로 돌리는 프로그램을 만들 수 있다

    📚 핵심 개념¶

    개념 1: for문 — "정해진 횟수만큼 반복"¶

    비유로 시작 🎡

    놀이공원 회전목마를 생각해 보세요. "3바퀴 돌고 끝!" 처럼 몇 번 반복할지 미리 정해진 상황에 딱 맞는 게 for문이에요.

    정확한 정의

    for문은 정해진 범위만큼 코드를 반복 실행하는 구문입니다.

    for i in range(3):
    print(f"{i}번째 반복!")

    range(3)은 0, 1, 2 — 총 3개의 숫자를 만들어 줍니다. 변수 i가 매번 다음 숫자를 받아서 블록 안의 코드를 실행하죠.

    예시로 확인

    0번째 반복!
1번째 반복!
2번째 반복!

    💡 range(시작, 끝)으로 쓰면 시작 숫자를 지정할 수 있어요. range(1, 4)는 1, 2, 3을 만듭니다.

    흐름을 그림으로 보면 👇

    flowchart TD A["i = 0부터 시작"] --> B{"i < 3 인가?"} B -- 예 --> C["블록 실행<br/>print(i)"] C --> D["i를 1 증가"] D --> B B -- 아니오 --> E["반복 종료 ✅"]

    핵심은 초기값 → 조건 확인 → 실행 → 증가 → 다시 조건 확인의 순환입니다.

    개념 2: while문 — "조건이 참인 동안 계속"¶

    비유로 시작 🔄

    "배부를 때까지 먹어!" — 몇 번 먹을지 미리 모르지만, 조건(배부름)이 만족될 때까지 계속하는 게 while문이에요.

    정확한 정의

    while문은 조건이 참(True)인 동안 코드를 반복합니다.

    count = 0
while count < 3:
    print(f"{count}번째 반복!")
    count += 1  # 이걸 빼먹으면 무한루프! 😱

    for vs while, 언제 뭘 쓸까?

    flowchart LR Q{"반복 횟수를<br/>미리 아는가?"} -- 안다 --> F["for문 사용"] Q -- 모른다 --> W["while문 사용"]
    • for문: "질문 4개를 순서대로" 처럼 횟수가 정해진 경우
    • while문: "사용자가 '그만'이라고 할 때까지" 처럼 언제 끝날지 모르는 경우

    🔨 따라하기¶

    지난 장에서 질문 1개에 대해 E/I를 판별했죠? 이제 질문 4개를 반복문으로 돌려봅시다! 🚀

    Step 1: 질문 목록 준비하기¶

    # MBTI E/I 질문 4개를 리스트에 담기
questions = [
    "주말에 친구들과 만나는 게 좋다 (1) vs 혼자 쉬는 게 좋다 (2)",
    "새로운 사람을 만나면 신난다 (1) vs 긴장된다 (2)",
    "모임에서 먼저 말을 건다 (1) vs 누가 말 걸어주길 기다린다 (2)",
    "사람이 많은 곳에서 에너지를 얻는다 (1) vs 소모된다 (2)"
]

    리스트([])는 여러 데이터를 순서대로 담는 상자예요. 나중에 자세히 배우니 지금은 "질문 묶음"이라고만 생각하세요!

    Step 2: for문으로 질문 반복 출력¶

    for i in range(4):
    print(f"\n질문 {i + 1}: {questions[i]}")
    answer = input("선택 (1 또는 2): ")

    questions[i]는 리스트에서 i번째 질문을 꺼내는 방법입니다. i가 0, 1, 2, 3으로 바뀌면서 질문이 하나씩 출력돼요.

    Step 3: 조건문을 넣어 점수 누적하기¶

    e_score = 0  # E 점수 누적용

for i in range(4):
    print(f"\n질문 {i + 1}: {questions[i]}")
    answer = input("선택 (1 또는 2): ")

    if answer == "1":
        e_score += 1  # E 성향이면 +1

    e_score += 1 은 e_score = e_score + 1과 같아요. 반복할 때마다 점수가 쌓입니다!

    Step 4: 결과 판별하기¶

    print(f"\n=== 결과 ===")
print(f"E 점수: {e_score} / 4")

if e_score >= 3:
    print("당신은 E(외향형)에 가깝습니다! 🎉")
elif e_score >= 2:
    print("E와 I의 중간쯤이네요! 🤔")
else:
    print("당신은 I(내향형)에 가깝습니다! 📚")

    ⚠️ 주의할 점¶

    1. while문의 무한루프 조심! 🚨

    while 안에서 조건을 변화시키는 코드(예: count += 1)를 빼먹으면 영원히 멈추지 않습니다. 프로그램이 멈추지 않으면 Ctrl + C로 강제 종료하세요.

    2. range(4)는 0부터 3까지!

    range(4)가 만드는 숫자는 0, 1, 2, 3이지 1, 2, 3, 4가 아닙니다. 그래서 화면에 보여줄 때는 i + 1로 표시했어요.

    ✅ 점검하기¶

    1. range(5)는 어떤 숫자들을 만들어 줄까요?

    정답 확인 0, 1, 2, 3, 4 — 총 5개의 숫자를 만듭니다. 0부터 시작해서 5 **미만**까지!

    2. 반복 횟수를 미리 알 때는 for문, 모를 때는 while문을 쓴다. 그렇다면 "사용자가 '끝'을 입력할 때까지 질문을 반복"하려면 어떤 반복문이 적절할까요?

    정답 확인 `while`문이 적절합니다. 사용자가 언제 '끝'을 입력할지 모르므로 `while answer != "끝":` 형태로 작성할 수 있어요.

    3. 아래 코드의 실행 결과는? 

    total = 0
for i in range(3):
    total += i
print(total)

    정답 확인 `3`이 출력됩니다. i가 0, 1, 2를 거치면서 total에 누적되어 0 + 1 + 2 = 3이 됩니다.
