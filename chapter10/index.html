    비트연산자 맛보기 — 0과 1로 말하는 컴퓨터¶

    🎯 이 장에서 배우는 것¶

    • 컴퓨터가 데이터를 2진수(0과 1)로 저장하는 원리를 이해할 수 있다
    • &, |, ^, ~, <<, >> 비트연산자의 동작을 설명할 수 있다
    • 비트연산이 하드웨어 제어에서 왜 필요한지 감을 잡을 수 있다

    📚 핵심 개념¶

    개념 1: 2진수 — 컴퓨터의 모국어¶

    비유로 시작 🔦

    방에 전등 스위치가 8개 나란히 있다고 상상해보세요. 각 스위치는 켜짐(1) 또는 꺼짐(0) 두 가지 상태뿐이에요. 컴퓨터는 이 단순한 ON/OFF 조합으로 모든 숫자, 문자, 이미지를 표현합니다!

    정확한 정의

    2진수(binary)는 0과 1 두 숫자만 사용하는 수 체계입니다. 컴퓨터 메모리의 가장 작은 단위인 비트(bit) 하나가 0 또는 1을 저장하고, 8개의 비트가 모이면 1바이트(byte) 가 됩니다.

    예시로 확인

    • 10진수 5 → 2진수 00000101 (오른쪽부터 1자리=1, 2자리=0, 4자리=1 → 4+1=5)
    • 10진수 13 → 2진수 00001101 (8+4+1=13)

    Python에서는 bin() 함수로 바로 확인할 수 있어요:

    print(bin(5))   # 0b101
print(bin(13))  # 0b1101

    0b는 "이건 2진수야!"라는 표시입니다.

    개념 2: 비트연산자 — 스위치를 조작하는 6가지 도구¶

    비유로 시작 🎛️

    8개 전등 스위치 앞에 서서, 특정 스위치만 골라 켜거나 끄거나 뒤집는 도구가 있다면? 그게 바로 비트연산자입니다!

    6가지 연산자 한눈에 보기

    • & (AND): 두 비트가 모두 1일 때만 1 → "둘 다 켜져 있어야 켜짐"
    • | (OR): 둘 중 하나라도 1이면 1 → "하나만 켜져도 켜짐"
    • ^ (XOR): 두 비트가 서로 다를 때 1 → "다르면 켜짐"
    • ~ (NOT): 비트를 뒤집기 → "켜진 건 끄고, 꺼진 건 켜기"
    • << (왼쪽 시프트): 비트를 왼쪽으로 밀기 → 값이 2배씩 커짐
    • >> (오른쪽 시프트): 비트를 오른쪽으로 밀기 → 값이 반씩 줄어듦
    flowchart LR A["1 0 1 1"] -- "&(AND)\n1 1 0 1" --> B["1 0 0 1"] C["1 0 1 1"] -- "|(OR)\n1 1 0 1" --> D["1 1 1 1"] E["1 0 1 1"] -- "^(XOR)\n1 1 0 1" --> F["0 1 1 0"]

    🔨 따라하기¶

    Step 1: AND, OR, XOR 직접 확인하기¶

    a = 0b1011  # 10진수 11
b = 0b1101  # 10진수 13

print(f"a     = {a:04b} ({a})")
print(f"b     = {b:04b} ({b})")
print(f"a & b = {a & b:04b} ({a & b})")   # AND
print(f"a | b = {a | b:04b} ({a | b})")   # OR
print(f"a ^ b = {a ^ b:04b} ({a ^ b})")   # XOR

    실행 결과: 

    a     = 1011 (11)
b     = 1101 (13)
a & b = 1001 (9)
a | b = 1111 (15)
a ^ b = 0110 (6)

    💡 {a:04b}는 "2진수로 4자리까지 보여줘"라는 포맷입니다. 신기하죠?

    Step 2: NOT과 시프트 연산¶

    c = 0b0101  # 10진수 5

# NOT: Python은 정수 크기가 무한이라 & 0xFF로 8비트만 볼게요
print(f"~c (8비트) = {~c & 0xFF:08b} ({~c & 0xFF})")  # NOT

# 시프트
print(f"c << 1 = {c << 1:08b} ({c << 1})")  # 왼쪽 시프트: 5 → 10
print(f"c >> 1 = {c >> 1:08b} ({c >> 1})")  # 오른쪽 시프트: 5 → 2

    실행 결과: 

    ~c (8비트) = 11111010 (250)
c << 1 = 00001010 (10)
c >> 1 = 00000010 (2)

    🤔 왼쪽 시프트 1번 = ×2, 오른쪽 시프트 1번 = ÷2(소수점 버림). 곱셈/나눗셈보다 빠른 계산법이에요!

    Step 3: 🔦 8비트 LED 제어 시뮬레이션¶

    이제 진짜 하드웨어 느낌을 내봅시다! 8개 LED를 비트연산으로 켜고 끄는 프로그램입니다.

    def show_leds(state):
    """8비트 LED 상태를 시각적으로 보여주기"""
    leds = ""
    for i in range(7, -1, -1):  # 7번 비트부터 0번 비트까지
        if state & (1 << i):    # 해당 비트가 1인지 확인
            leds += "💡"
        else:
            leds += "⚫"
    print(f"  LED: {leds}  (값: {state:08b})")

# 처음엔 모두 꺼짐
leds = 0b00000000
print("== 초기 상태 ==")
show_leds(leds)

# 3번 LED 켜기 (OR 사용)
leds = leds | (1 << 3)
print("\n== 3번 LED 켜기 (OR) ==")
show_leds(leds)

# 7번, 0번 LED도 켜기
leds = leds | (1 << 7) | (1 << 0)
print("\n== 7번, 0번 LED 추가 (OR) ==")
show_leds(leds)

# 3번 LED 끄기 (AND + NOT 사용)
leds = leds & ~(1 << 3)
print("\n== 3번 LED 끄기 (AND + NOT) ==")
show_leds(leds)

# 전체 토글 (XOR)
leds = leds ^ 0xFF
print("\n== 전체 반전 (XOR) ==")
show_leds(leds)

    실행 결과: 

    == 초기 상태 ==
  LED: ⚫⚫⚫⚫⚫⚫⚫⚫  (값: 00000000)

== 3번 LED 켜기 (OR) ==
  LED: ⚫⚫⚫⚫💡⚫⚫⚫  (값: 00001000)

== 7번, 0번 LED 추가 (OR) ==
  LED: 💡⚫⚫⚫💡⚫⚫💡  (값: 10001001)

== 3번 LED 끄기 (AND + NOT) ==
  LED: 💡⚫⚫⚫⚫⚫⚫💡  (값: 10000001)

== 전체 반전 (XOR) ==
  LED: ⚫💡💡💡💡💡💡⚫  (값: 01111110)

    이게 바로 아두이노나 ESP32에서 GPIO 핀을 제어하는 실제 원리예요! 🎉

    📝 전체 코드¶

    # === 비트연산자 맛보기 — 8비트 LED 시뮬레이터 ===

def show_leds(state):
    """8비트 LED 상태를 시각적으로 보여주기"""
    leds = ""
    for i in range(7, -1, -1):
        if state & (1 << i):
            leds += "💡"
        else:
            leds += "⚫"
    print(f"  LED: {leds}  (값: {state:08b})")

# 기본 비트연산 확인
a, b = 0b1011, 0b1101
print(f"a & b = {a & b:04b}")   # AND
print(f"a | b = {a | b:04b}")   # OR
print(f"a ^ b = {a ^ b:04b}")   # XOR
print(f"a << 1 = {a << 1:04b}") # 왼쪽 시프트
print()

# LED 제어 시뮬레이션
leds = 0b00000000
show_leds(leds)

leds = leds | (1 << 3)          # 3번 켜기
show_leds(leds)

leds = leds | (1 << 7) | (1 << 0)  # 7번, 0번 켜기
show_leds(leds)

leds = leds & ~(1 << 3)         # 3번 끄기
show_leds(leds)

leds = leds ^ 0xFF              # 전체 반전
show_leds(leds)

    ⚠️ 주의할 점¶

    1. ~(NOT) 연산 결과가 이상해 보여요! Python의 정수는 크기 제한이 없어서 ~5는 -6이 됩니다. 8비트로 보고 싶으면 ~5 & 0xFF 처럼 마스크를 씌워주세요.

    2. 비트연산자 &, |와 논리연산자 and, or는 다릅니다! &는 비트 하나하나를 비교하고, and는 값 전체의 참/거짓을 판단합니다. 헷갈리기 쉬우니 용도를 구분해서 써주세요.

    ✅ 점검하기¶

    1. 0b1100 & 0b1010의 결과는 2진수로 무엇일까요?

    정답 확인 `0b1000` (10진수 8). AND는 **둘 다 1인 자리만** 1이 됩니다. 세 번째 자리(왼쪽에서)만 둘 다 1이에요.

    2. 특정 비트를 켤 때는 어떤 연산자, 끌 때는 어떤 연산자 조합을 쓸까요?

    정답 확인 - **켜기**: `|` (OR) → `leds = leds | (1 << n)` - **끄기**: `& ~` (AND + NOT) → `leds = leds & ~(1 << n)` OR는 해당 비트를 무조건 1로 만들고, AND+NOT은 해당 비트만 0으로 만듭니다.

    3. 5 << 2의 결과는 얼마일까요? 왜 그렇게 되나요?

    정답 확인 `20`입니다. 왼쪽 시프트 1번은 ×2이므로, 2번이면 ×4. `5 × 4 = 20`. 2진수로 보면 `00000101` → `00010100`.
