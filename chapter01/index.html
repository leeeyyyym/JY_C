    C언어, 파이썬과 뭐가 다를까?¶

    Part 1 · C언어와의 첫 만남

    🎯 이 장에서 배우는 것¶

    • C언어와 파이썬의 핵심 차이(컴파일 vs 인터프리터)를 설명할 수 있다
    • C언어 개발 환경을 설정하고, 첫 번째 프로그램을 컴파일·실행할 수 있다

    📚 핵심 개념¶

    개념 1: 컴파일 vs 인터프리터 — 번역 방식의 차이¶

    비유로 시작 ☕

    파이썬은 동시통역사예요. 발표자가 한 문장 말하면, 통역사가 바로 한 문장 번역해줍니다. C언어는 출판 번역가예요. 원고 전체를 먼저 번역하고, 완성된 책을 한꺼번에 전달합니다.

    정확한 정의

    • 인터프리터 방식(파이썬): 코드를 한 줄씩 읽으면서 바로 실행합니다. 코드를 고치면 즉시 다시 실행할 수 있어 편리하지만, 매번 통역 과정을 거치므로 속도가 느릴 수 있어요.
    • 컴파일 방식(C언어): 소스 코드 전체를 먼저 기계어로 번역(컴파일)해서 실행 파일을 만듭니다. 번역은 한 번만 하면 되니까, 완성된 실행 파일은 매우 빠르게 동작해요.

    흐름을 그림으로 확인 👇

    flowchart LR subgraph 파이썬 A1["소스 코드\n(.py)"] -->|"한 줄씩 해석"| A2["인터프리터"] -->|"바로 실행"| A3["결과 출력"] end subgraph C언어 B1["소스 코드\n(.c)"] -->|"전체 번역"| B2["컴파일러"] -->|"실행 파일 생성"| B3["실행 파일\n(.exe 등)"] -->|"실행"| B4["결과 출력"] end

    💡 C언어는 "컴파일 → 실행" 이라는 두 단계를 거친다는 것, 꼭 기억하세요!

    개념 2: 문법 차이 — 세미콜론, 중괄호, #include¶

    파이썬 코드와 C언어 코드를 나란히 볼게요.

    파이썬으로 "Hello" 출력

    print("Hello")

    C언어로 "Hello" 출력

    #include <stdio.h>

int main(void) {
    printf("Hello\n");
    return 0;
}

    달라진 부분이 눈에 보이죠? 핵심만 정리하면 이래요.

    • #include <stdio.h> — "printf를 쓸 거니까 표준 입출력 도구 상자를 가져와 줘!" 라는 뜻이에요. 파이썬의 import와 비슷합니다.
    • int main(void) { ... } — 프로그램의 시작점이에요. C언어는 항상 main 함수에서 출발합니다.
    • 세미콜론 ; — 문장이 끝날 때마다 붙여요. 파이썬은 줄바꿈이 문장 끝이지만, C언어는 ;이 문장 끝입니다. (빼먹으면 에러! 🚨)
    • 중괄호 { } — 코드 블록을 감싸요. 파이썬의 들여쓰기 역할을 중괄호가 대신합니다.
    • return 0; — "프로그램이 정상적으로 끝났어!" 라고 운영체제에 알려주는 신호예요.

    🔨 따라하기: 첫 번째 C 프로그램 실행¶

    Step 1: 개발 환경 준비¶

    온라인 컴파일러를 사용하면 설치 없이 바로 시작할 수 있어요.

    👉 https://www.onlinegdb.com/ 에 접속하세요.

    • 상단 언어 선택에서 C 를 고릅니다.
    • 가운데 편집기 창에 코드를 작성하면 돼요.

    🖥️ 로컬 환경을 원한다면? Windows: MinGW 설치 후 gcc 명령 사용 / Mac: 터미널에서 xcode-select --install / Linux: sudo apt install gcc

    Step 2: 코드 작성¶

    편집기에 아래 코드를 그대로 입력하세요.

    #include <stdio.h>

int main(void) {
    printf("MBTI 게임에 오신 것을 환영합니다!\n");
    return 0;
}
    • printf — 파이썬의 print에 해당해요.
    • \n — 줄바꿈 문자. 파이썬 print는 자동 줄바꿈이지만 C의 printf는 직접 넣어야 합니다.

    Step 3: 컴파일 & 실행¶

    OnlineGDB 상단의 ▶ Run 버튼을 클릭하세요.

    내부적으로 아래 두 단계가 일어나요.

    flowchart LR S["hello.c\n(내가 쓴 코드)"] -->|"gcc 컴파일"| E["실행 파일"] -->|"실행"| R["화면에 출력"]

    실행 결과:

    MBTI 게임에 오신 것을 환영합니다!

    축하해요! 🎉 여러분의 첫 C 프로그램이 성공적으로 실행되었습니다.

    Step 4: 살짝 바꿔보기¶

    printf 줄을 하나 더 추가해볼까요?

    #include <stdio.h>

int main(void) {
    printf("MBTI 게임에 오신 것을 환영합니다!\n");
    printf("당신의 MBTI는 무엇인가요?\n");
    return 0;
}

    실행 결과:

    MBTI 게임에 오신 것을 환영합니다!
당신의 MBTI는 무엇인가요?

    🔑 printf를 여러 번 쓰면 여러 줄을 출력할 수 있어요. 각 문장 끝에 ; 잊지 마세요!

    📝 전체 코드¶

    #include <stdio.h>

int main(void) {
    printf("MBTI 게임에 오신 것을 환영합니다!\n");
    printf("당신의 MBTI는 무엇인가요?\n");
    return 0;
}

    ⚠️ 주의할 점¶

    1. 세미콜론 ; 빼먹기 — C언어 초보가 가장 많이 하는 실수예요. 에러 메시지에 expected ';'이 보이면 바로 윗줄 끝을 확인하세요!
    2. printf와 print 혼동 — 파이썬 습관으로 print("Hello");라고 쓰면 컴파일 에러가 납니다. C에서는 반드시 printf 를 사용하세요.

    ✅ 점검하기¶

    1. 파이썬은 ( A ) 방식, C언어는 ( B ) 방식으로 코드를 실행합니다. A와 B는?

    정답 확인 A: **인터프리터**, B: **컴파일** 파이썬은 한 줄씩 해석해서 바로 실행하고, C언어는 전체를 기계어로 번역(컴파일)한 뒤 실행 파일을 만들어 실행합니다.

    2. 아래 C 코드에서 에러가 나는 이유는 무엇일까요?

    #include <stdio.h>

int main(void) {
    printf("Hello\n")
    return 0;
}
    정답 확인 `printf("Hello\n")` 뒤에 **세미콜론 `;`** 이 빠져 있습니다. `printf("Hello\n");` 으로 고치면 정상 동작해요.

    3. C언어에서 #include <stdio.h>는 어떤 역할을 하나요?

    정답 확인 `printf` 같은 **표준 입출력 함수**를 사용하기 위해 필요한 헤더 파일을 가져오는 것입니다. 파이썬의 `import`와 비슷한 역할이에요.
