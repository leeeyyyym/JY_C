    포인터 맛보기 — &와 *의 정체를 밝혀라¶

    🎯 이 장에서 배우는 것¶

    • 변수의 주소(&)와 포인터(*)의 개념을 비유로 이해할 수 있다
    • scanf에서 &를 써야 했던 이유를 설명할 수 있다
    • int *ptr = &x 패턴을 직접 작성하고 실행할 수 있다

    📚 핵심 개념¶

    개념: 주소(&)와 포인터(*)¶

    1. 비유로 시작 🏠

    변수는 집, 값은 집 안에 사는 사람이라고 생각해보세요.

    • int x = 10; → 10이라는 사람이 x라는 집에 살고 있어요
    • &x → "x라는 집의 주소 좀 알려줘!" (예: 서울시 강남구 123번지)
    • *ptr → "이 주소로 찾아가서 안에 사는 사람을 만나줘!"
    flowchart LR A["변수 x\n값: 10"] --- B["주소: 0x7fff1234"] C["포인터 ptr"] -->|"ptr = &x\n(주소 저장)"| B B -->|"*ptr\n(주소로 찾아가기)"| A

    2. 정확한 정의

    • &변수 — 해당 변수가 메모리 어디에 있는지, 그 주소를 반환
    • int *ptr — 주소를 저장하는 특별한 변수, 즉 포인터 선언
    • *ptr — 포인터가 가리키는 주소에 가서 값을 꺼냄(역참조)

    3. 예시로 확인

    int x = 10;
int *ptr = &x;  // ptr에 x의 주소를 저장

printf("x의 값: %d\n", x);       // 10
printf("x의 주소: %p\n", &x);    // 0x7fff... (매번 다름)
printf("ptr이 가리키는 값: %d\n", *ptr);  // 10

    💡 드디어 밝혀지는 비밀! scanf("%d", &x);에서 &x를 쓴 이유? scanf는 주소를 받아서 그 위치에 직접 값을 넣어주는 함수이기 때문이에요. 주소를 안 알려주면 어디에 넣을지 모르겠죠!

    🔨 따라하기¶

    Step 1: 포인터의 기본 동작 확인하기¶

    코드: 

    #include <stdio.h>

int main(void) {
    int score = 95;
    int *ptr = &score;  // score의 주소를 ptr에 저장

    printf("score의 값: %d\n", score);
    printf("score의 주소: %p\n", &score);
    printf("ptr에 저장된 주소: %p\n", ptr);
    printf("ptr로 꺼낸 값: %d\n", *ptr);

    // 포인터를 통해 값 변경!
    *ptr = 100;
    printf("변경 후 score: %d\n", score);

    return 0;
}

    실행 결과: 

    score의 값: 95
score의 주소: 0x7ffd3a2c
ptr에 저장된 주소: 0x7ffd3a2c
ptr로 꺼낸 값: 95
변경 후 score: 100

    🎉 *ptr = 100;으로 값을 바꿨더니 score도 바뀌었어요! 같은 주소를 가리키고 있으니 당연한 결과입니다.

    📝 전체 코드¶

    #include <stdio.h>

int main(void) {
    int score = 95;
    int *ptr = &score;

    printf("score의 값: %d\n", score);
    printf("score의 주소: %p\n", &score);
    printf("ptr에 저장된 주소: %p\n", ptr);
    printf("ptr로 꺼낸 값: %d\n", *ptr);

    *ptr = 100;
    printf("변경 후 score: %d\n", score);

    return 0;
}

    ⚠️ 주의할 점¶

    • 🚨 선언할 때의 *와 사용할 때의 *는 의미가 달라요! int *ptr은 "포인터를 만든다"는 선언, *ptr은 "주소로 찾아가라"는 역참조
    • 🚨 초기화 안 된 포인터를 쓰면 위험해요! 반드시 &변수로 유효한 주소를 넣어준 뒤 사용하세요

    ✅ 점검하기¶

    1. scanf("%d", &x);에서 &를 빼면 왜 문제가 될까요?

    정답 확인scanf는 값을 저장할 **메모리 주소**가 필요합니다. &를 빼면 x의 값(숫자)을 주소로 착각해서 엉뚱한 곳에 쓰려다 오류가 납니다.

    2. int *ptr = &x; 후 *ptr = 50;을 하면 x의 값은?

    정답 확인50입니다. ptr이 x의 주소를 가리키고 있으므로, *ptr로 값을 바꾸면 x 자체가 바뀝니다.

    3. &와 *의 역할을 한 문장으로 각각 설명해보세요.

    정답 확인&는 "변수의 주소를 알려줘", *는 "이 주소에 찾아가서 값을 꺼내줘"입니다.
