    조건문 — 선택에 따라 달라지는 반응¶

    🎯 이 장에서 배우는 것¶

    • if-else if-else 구문으로 조건에 따라 다른 코드를 실행할 수 있다
    • switch-case 구문으로 여러 선택지를 깔끔하게 분기할 수 있다
    • 사용자 입력에 따라 다른 반응을 출력하는 MBTI 질문을 구현할 수 있다

    📚 핵심 개념¶

    개념 1: if-else if-else (갈림길 표지판)¶

    비유로 시작 🚏

    조건문은 마치 갈림길 표지판과 같아요. "비가 오면 우산을 쓰고, 안 오면 그냥 나간다" — 우리가 매일 하는 이런 판단을, 컴퓨터에게 시키는 것이 바로 조건문입니다.

    flowchart TD A["조건 확인"] --> B{"비가 오나요?"} B -- "Yes" --> C["우산을 쓴다 ☂️"] B -- "No" --> D{"눈이 오나요?"} D -- "Yes" --> E["패딩을 입는다 🧥"] D -- "No" --> F["그냥 나간다 🚶"]

    정확한 정의

    if문은 조건식이 참(0이 아닌 값)이면 중괄호 안의 코드를 실행하고, 거짓(0)이면 건너뛰는 구문입니다.

    기본 구조:

    if (조건1) {
    // 조건1이 참일 때
} else if (조건2) {
    // 조건1은 거짓, 조건2가 참일 때
} else {
    // 모두 거짓일 때
}

    💡 파이썬과의 차이 3가지 - 조건식을 괄호 ()로 반드시 감싸야 한다 - 코드 블록을 중괄호 {}로 감싼다 (들여쓰기가 아님!) - elif 대신 else if (띄어쓰기 주의!)

    예시로 확인:

    int score = 85;

if (score >= 90) {
    printf("A학점!\n");
} else if (score >= 80) {
    printf("B학점!\n");   // ← 이게 실행됨!
} else {
    printf("더 힘내자!\n");
}

    score가 85이므로 첫 번째 조건(>=90)은 거짓, 두 번째 조건(>=80)은 참 → "B학점!" 이 출력됩니다.

    개념 2: switch-case (엘리베이터 버튼)¶

    비유로 시작 🛗

    switch는 마치 엘리베이터 버튼과 같아요. 1을 누르면 1층, 2를 누르면 2층 — 하나의 값에 따라 정해진 곳으로 바로 이동합니다.

    정확한 정의

    switch문은 하나의 변수 값을 여러 case와 비교해서, 일치하는 곳의 코드를 실행합니다.

    switch (변수) {
    case 값1:
        // 변수 == 값1일 때
        break;
    case 값2:
        // 변수 == 값2일 때
        break;
    default:
        // 어떤 case에도 안 맞을 때
        break;
}

    ⚡ break를 빼먹으면? 아래 case까지 줄줄이 실행됩니다! (이를 "fall-through"라 부릅니다) 반드시 각 case 끝에 break;를 넣으세요.

    🔨 따라하기: MBTI 질문 만들기¶

    하나의 MBTI 질문을 만들어서, 사용자의 선택에 따라 다른 반응을 보여주겠습니다.

    Step 1: 질문 출력하고 입력 받기¶

    #include <stdio.h>

int main(void) {
    int answer;

    printf("=== MBTI 테스트 ===\n");
    printf("주말에 에너지를 충전하는 방법은?\n");
    printf("1. 친구들과 신나게 놀기\n");
    printf("2. 집에서 혼자 조용히 쉬기\n");
    printf("선택 (1 또는 2): ");
    scanf("%d", &answer);

    return 0;
}

    아직 아무 반응도 없지만, 사용자의 답을 answer에 저장하는 데 성공했습니다! 👍

    Step 2: if-else로 반응 분기하기¶

    scanf 아래에 조건문을 추가합니다.

        if (answer == 1) {
        printf("\n🎉 당신은 E(외향형)에 가깝습니다!\n");
        printf("사람들과 함께할 때 에너지가 충전되는 타입이에요.\n");
    } else if (answer == 2) {
        printf("\n📚 당신은 I(내향형)에 가깝습니다!\n");
        printf("혼자만의 시간이 진정한 휴식인 타입이에요.\n");
    } else {
        printf("\n⚠️ 1 또는 2만 입력해주세요!\n");
    }

    🔍 =와 ==를 헷갈리지 마세요! =는 대입, ==는 비교입니다.

    Step 3: switch-case 버전으로도 만들어 보기¶

    같은 로직을 switch로 바꿔볼까요?

        switch (answer) {
        case 1:
            printf("\n🎉 당신은 E(외향형)에 가깝습니다!\n");
            break;
        case 2:
            printf("\n📚 당신은 I(내향형)에 가깝습니다!\n");
            break;
        default:
            printf("\n⚠️ 1 또는 2만 입력해주세요!\n");
            break;
    }

    정수 값을 비교할 때는 switch가 더 깔끔하게 읽히죠? 선택지가 3개, 4개로 늘어날수록 switch의 장점이 커집니다.

    📝 전체 코드¶

    #include <stdio.h>

int main(void) {
    int answer;

    // 질문 출력
    printf("=== MBTI 테스트 ===\n");
    printf("주말에 에너지를 충전하는 방법은?\n");
    printf("1. 친구들과 신나게 놀기\n");
    printf("2. 집에서 혼자 조용히 쉬기\n");
    printf("선택 (1 또는 2): ");
    scanf("%d", &answer);

    // 조건에 따라 다른 반응 출력
    if (answer == 1) {
        printf("\n🎉 당신은 E(외향형)에 가깝습니다!\n");
        printf("사람들과 함께할 때 에너지가 충전되는 타입이에요.\n");
    } else if (answer == 2) {
        printf("\n📚 당신은 I(내향형)에 가깝습니다!\n");
        printf("혼자만의 시간이 진정한 휴식인 타입이에요.\n");
    } else {
        printf("\n⚠️ 1 또는 2만 입력해주세요!\n");
    }

    return 0;
}

    실행 결과 (2를 입력한 경우):

    === MBTI 테스트 ===
주말에 에너지를 충전하는 방법은?
1. 친구들과 신나게 놀기
2. 집에서 혼자 조용히 쉬기
선택 (1 또는 2): 2

📚 당신은 I(내향형)에 가깝습니다!
혼자만의 시간이 진정한 휴식인 타입이에요.

    ⚠️ 주의할 점¶

    • =와 == 혼동 주의! if (answer = 1)이라고 쓰면 비교가 아니라 대입이 되어, 항상 참으로 실행됩니다. 비교는 반드시 == 두 개!
    • switch에서 break 필수! break를 빼먹으면 다음 case까지 연속 실행됩니다. 의도한 게 아니라면 반드시 넣으세요.

    ✅ 점검하기¶

    1. 다음 코드의 출력 결과는?

    int x = 5;
if (x > 10) {
    printf("A");
} else if (x > 3) {
    printf("B");
} else {
    printf("C");
}
    정답 확인 **B** — `x`가 5이므로 첫 번째 조건(`>10`)은 거짓, 두 번째 조건(`>3`)은 참이라 "B"가 출력됩니다.

    2. switch문에서 break를 빼먹으면 어떤 일이 일어나나요?

    정답 확인 일치하는 `case`부터 아래의 모든 `case` 코드가 연속으로 실행됩니다 (fall-through). 예를 들어 `case 1:`에서 `break`가 없으면 `case 2:`의 코드까지 실행됩니다.

    3. if (score = 100)과 if (score == 100)의 차이는?

    정답 확인 `score = 100`은 score에 100을 **대입**하고, 대입된 값(100)이 0이 아니므로 **항상 참**이 됩니다. `score == 100`은 score가 100인지 **비교**합니다. 조건문에서는 반드시 `==`를 써야 합니다.
