    변수와 자료형 — 이름표를 붙이자¶

    🎯 이 장에서 배우는 것¶

    • int, float, char 등 기본 자료형을 구분하고 변수를 선언할 수 있다
    • 파이썬과 달리 자료형을 명시해야 하는 이유를 설명할 수 있다
    • #define과 const를 사용하여 상수를 정의할 수 있다

    📚 핵심 개념¶

    개념 1: 변수와 자료형 — 크기가 정해진 서랍¶

    비유로 시작 🗄️

    파이썬에서 변수는 "마법 가방" 같았어요. 숫자를 넣으면 알아서 늘어나고, 문자를 넣어도 그냥 들어갔죠. 하지만 C언어에서 변수는 크기가 미리 정해진 서랍이에요. 작은 서랍에 큰 물건은 못 넣듯, 어떤 크기의 서랍을 쓸지 먼저 말해줘야 합니다.

    정확한 정의

    C언어에서 변수를 선언할 때는 반드시 자료형(type) 을 명시해야 합니다. 자료형은 "이 서랍이 몇 바이트 크기이고, 어떤 종류의 데이터를 담는지" 알려주는 이름표입니다.

    파이썬 vs C 비교

    # 파이썬 — 자료형을 안 써도 됨
x = 10
name = "철수"

    // C언어 — 자료형을 반드시 명시!
int x = 10;
char name[] = "철수";

    💡 왜 C는 자료형을 요구할까? C는 메모리를 직접 관리하는 언어예요. 컴퓨터에게 "4바이트짜리 서랍을 하나 만들어줘"라고 정확히 알려줘야 메모리를 효율적으로 쓸 수 있거든요. 파이썬은 이걸 뒤에서 자동으로 해주지만, C는 프로그래머가 직접 합니다.

    기본 자료형 한눈에 보기

    graph LR A["C 기본 자료형"] --> B["int\n정수 · 4바이트\n예: 10, -3"] A --> C["float\n실수 · 4바이트\n예: 3.14"] A --> D["double\n실수(정밀) · 8바이트\n예: 3.141592653"] A --> E["char\n문자 1개 · 1바이트\n예: 'A'"]
    • int → 정수를 담는 서랍 (4바이트, 약 ±21억)
    • float → 소수점 있는 수 (4바이트, 소수점 아래 6~7자리)
    • double → 더 정밀한 소수 (8바이트, 소수점 아래 15자리)
    • char → 문자 하나 (1바이트, 'A', 'z' 등)

    개념 2: 상수 — 절대 바뀌지 않는 값¶

    비유로 시작 🔒

    MBTI 게임을 만든다고 해볼게요. 질문은 항상 12개, 유형은 항상 16개잖아요? 이렇게 절대 변하면 안 되는 값을 상수라고 합니다. 자물쇠가 걸린 서랍이라고 생각하면 돼요!

    두 가지 방법

    // 방법 1: #define (전처리기 매크로)
#define QUESTION_COUNT 12
#define MAX_SCORE 100

// 방법 2: const 키워드
const int maxScore = 100;
const float pi = 3.14f;
    • #define → 컴파일 전에 텍스트를 치환합니다. 자료형이 없고, 세미콜론도 안 붙여요.
    • const → 자료형이 있는 "읽기 전용 변수"예요. 실수로 값을 바꾸려 하면 컴파일 에러가 납니다.

    🎯 팁: 간단한 숫자 상수는 #define, 자료형이 중요한 상수는 const를 쓰는 게 일반적이에요.

    🔨 따라하기¶

    MBTI 게임의 데이터 틀을 잡아봅시다! 🎮

    Step 1: 기본 변수 선언하기¶

    #include <stdio.h>

int main(void) {
    // 다양한 자료형으로 변수 선언
    int score = 0;           // 점수 (정수)
    float percentage = 0.0f; // 백분율 (실수)
    char grade = 'A';        // 등급 (문자 하나)

    printf("점수: %d\n", score);
    printf("백분율: %.1f\n", percentage);
    printf("등급: %c\n", grade);

    return 0;
}

    실행 결과: 

    점수: 0
백분율: 0.0
등급: A

    📌 %d는 정수, %f는 실수, %c는 문자를 출력하는 서식 지정자예요. 자료형마다 짝이 다릅니다!

    Step 2: 상수 정의하고 활용하기¶

    #include <stdio.h>

#define QUESTION_COUNT 12    // 질문 수 (절대 불변)
#define GAME_TITLE "MBTI 테스트"

int main(void) {
    const int maxScore = 100;  // 최대 점수

    printf("=== %s ===\n", GAME_TITLE);
    printf("총 질문 수: %d\n", QUESTION_COUNT);
    printf("최대 점수: %d\n", maxScore);

    // maxScore = 200;  // ❌ 에러! const는 수정 불가

    return 0;
}

    실행 결과: 

    === MBTI 테스트 ===
총 질문 수: 12
최대 점수: 100

    Step 3: sizeof로 서랍 크기 확인하기¶

    #include <stdio.h>

int main(void) {
    printf("int 크기: %lu바이트\n", sizeof(int));
    printf("float 크기: %lu바이트\n", sizeof(float));
    printf("double 크기: %lu바이트\n", sizeof(double));
    printf("char 크기: %lu바이트\n", sizeof(char));

    return 0;
}

    실행 결과: 

    int 크기: 4바이트
float 크기: 4바이트
double 크기: 8바이트
char 크기: 1바이트

    💡 sizeof는 해당 자료형이 메모리에서 차지하는 크기를 알려줘요. 서랍 크기를 재는 줄자라고 생각하세요! 📏

    Step 4: MBTI 게임 데이터 틀 완성¶

    #include <stdio.h>

#define QUESTION_COUNT 12
#define MAX_NAME_LENGTH 50

int main(void) {
    // 플레이어 정보
    char playerName[MAX_NAME_LENGTH];  // 이름 저장용 문자 배열
    int totalScore = 0;
    char mbtiType[5];  // "ENFP" + 널문자 = 5칸

    // 이름 입력받기
    printf("이름을 입력하세요: ");
    scanf("%s", playerName);

    printf("\n안녕하세요, %s님!\n", playerName);
    printf("총 %d개의 질문에 답해주세요.\n", QUESTION_COUNT);
    printf("현재 점수: %d\n", totalScore);

    return 0;
}

    실행 결과 (사용자가 "민수"를 입력한 경우): 

    이름을 입력하세요: 민수

안녕하세요, 민수님!
총 12개의 질문에 답해주세요.
현재 점수: 0

    📝 전체 코드¶

    #include <stdio.h>

// 상수 정의
#define QUESTION_COUNT 12
#define MAX_NAME_LENGTH 50
#define GAME_TITLE "MBTI 성격유형 테스트"

int main(void) {
    const int maxScore = 100;

    // 변수 선언 — 다양한 자료형
    char playerName[MAX_NAME_LENGTH];  // 문자 배열 (이름)
    int totalScore = 0;                // 정수 (점수)
    float percentage = 0.0f;           // 실수 (백분율)
    char grade = '-';                  // 문자 (등급)

    // 게임 시작
    printf("=== %s ===\n\n", GAME_TITLE);
    printf("이름을 입력하세요: ");
    scanf("%s", playerName);

    // 정보 출력
    printf("\n%s님, 환영합니다!\n", playerName);
    printf("총 질문 수: %d개\n", QUESTION_COUNT);
    printf("최대 점수: %d점\n", maxScore);
    printf("현재 점수: %d점\n", totalScore);
    printf("백분율: %.1f%%\n", percentage);
    printf("등급: %c\n", grade);

    return 0;
}

    ⚠️ 주의할 점¶

    1. 선언 없이 사용하면 에러! 파이썬 습관으로 score = 10;이라고 쓰면 C 컴파일러가 "score가 뭔데?"라고 에러를 냅니다. 반드시 int score = 10;처럼 자료형을 붙이세요.

    2. #define에 세미콜론 붙이지 마세요! #define MAX 100;이라고 쓰면 세미콜론까지 치환되어 엉뚱한 에러가 발생합니다. #define MAX 100이 올바른 형태예요.

    ✅ 점검하기¶

    1. 파이썬에서는 x = 10이면 되는데, C에서 자료형을 명시해야 하는 이유는 무엇인가요?

    정답 확인 C는 메모리를 직접 관리하는 언어이기 때문에, 변수에 몇 바이트의 메모리를 할당할지 컴파일러에게 미리 알려줘야 합니다. 자료형이 그 역할을 합니다.

    2. int, float, char 각각의 크기(바이트)와 용도를 말해보세요.

    정답 확인 - **int**: 4바이트, 정수를 저장 (예: 점수, 개수) - **float**: 4바이트, 소수점이 있는 실수를 저장 (예: 백분율, 평균) - **char**: 1바이트, 문자 하나를 저장 (예: 'A', 'z')

    3. #define과 const의 차이점은 무엇인가요?

    정답 확인 - `#define`은 컴파일 전에 텍스트를 치환하는 전처리기 명령으로, 자료형이 없습니다. - `const`는 자료형이 있는 읽기 전용 변수로, 값을 변경하려 하면 컴파일 에러가 발생합니다.
