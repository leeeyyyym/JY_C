    Chapter 11: MBTI 게임 최종 완성 — 모든 것을 하나로! 🎉¶

    🎯 이 장에서 배우는 것¶

    • 1~10차시에서 배운 개념들을 하나의 완성된 MBTI 게임 프로그램으로 통합할 수 있다
    • 완성된 코드의 전체 흐름을 "조감도"처럼 설명할 수 있다
    • C언어 기초가 임베디드(아두이노/ESP32) 프로그래밍으로 어떻게 이어지는지 큰 그림을 그릴 수 있다

    📚 핵심 개념¶

    개념 1: 프로그램 통합 — 퍼즐 완성하기 🧩¶

    1. 비유로 시작: "지금까지 우리는 퍼즐 조각을 하나씩 만들었어요. 변수라는 조각, 조건문이라는 조각, 함수라는 조각… 이제 이 조각들을 맞춰서 하나의 그림을 완성할 차례예요!"

    2. 정확한 정의: 프로그램 통합이란, 개별적으로 학습한 개념(변수, 배열, 조건문, 반복문, 함수, 구조체)을 하나의 실행 흐름 안에서 유기적으로 연결하는 것입니다.

    3. 예시로 확인: MBTI 게임의 실행 흐름을 살펴볼까요?

    flowchart TD A["🎬 시작: 이름 입력<br/>(변수, scanf)"] --> B["📋 질문 출력<br/>(배열, 구조체, 반복문)"] B --> C["✍️ 답변 수집<br/>(scanf, 조건문)"] C --> D{"모든 질문 끝?"} D -- 아니오 --> B D -- 네 --> E["🧮 점수 계산<br/>(함수, 배열)"] E --> F["🔤 MBTI 판정<br/>(조건문, 함수)"] F --> G["📊 결과 출력<br/>(printf, 구조체)"]

    이 흐름도의 각 단계가 바로 여러분이 차시별로 배운 내용입니다!

    개념 2: C언어에서 임베디드로 — 다리 건너기 🌉¶

    1. 비유로 시작: "C언어는 '만국 공통어'와 같아요. 컴퓨터에서 게임을 만들 때도, 아두이노에서 LED를 켤 때도, 같은 문법을 사용하거든요."

    2. 정확한 정의: 임베디드 프로그래밍은 작은 컴퓨터(마이크로컨트롤러)에 C언어로 명령을 내려 센서를 읽고 모터를 돌리는 것입니다. 우리가 배운 변수, 함수, 조건문이 그대로 쓰입니다.

    3. 예시로 확인:

    4. 변수 → 센서값 저장: int temperature = 25;
    5. 조건문 → 제어 판단: if (temperature > 30) { 팬_켜기(); }
    6. 함수 → 동작 묶기: void LED_켜기() { ... }
    7. 반복문 → 계속 센서 읽기: while(1) { 센서_읽기(); }

    🔨 따라하기: MBTI 게임 완성!¶

    Step 1: 구조체와 질문 배열 준비¶

    지금까지 배운 구조체로 질문 데이터를 정의합니다.

    #include <stdio.h>
#include <string.h>

// 구조체 — 질문 하나의 틀 (8차시)
typedef struct {
    char question[100];  // 질문 텍스트
    char optionA[50];    // A 선택지
    char optionB[50];    // B 선택지
    int dimension;       // 0:EI, 1:SN, 2:TF, 3:JP
} Question;

    Step 2: 점수 계산 함수와 MBTI 판정 함수¶

    함수로 기능을 깔끔하게 분리합니다.

    // MBTI 유형 문자열 만들기 (함수 — 6차시)
void determineMBTI(int scores[], char result[]) {
    result[0] = (scores[0] >= 0) ? 'E' : 'I';
    result[1] = (scores[1] >= 0) ? 'S' : 'N';
    result[2] = (scores[2] >= 0) ? 'T' : 'F';
    result[3] = (scores[3] >= 0) ? 'J' : 'P';
    result[4] = '\0';  // 문자열 끝 표시
}

    💡 A를 선택하면 +1, B를 선택하면 -1로 점수를 누적하는 간단한 방식이에요!

    Step 3: 메인 함수에서 모든 것을 연결¶

    int main() {
    // 질문 배열 초기화 (배열 — 7차시)
    Question quiz[8] = {
        {"주말에 에너지를 충전하는 방법은?",
         "A: 친구들과 만남", "B: 혼자만의 시간", 0},
        {"새로운 사람을 만나면?",
         "A: 먼저 말을 건다", "B: 상대가 말할 때까지 기다린다", 0},
        {"정보를 받아들일 때?",
         "A: 구체적 사실 중심", "B: 가능성과 상상 중심", 1},
        {"새 프로젝트를 시작하면?",
         "A: 검증된 방법 선호", "B: 새로운 방법 시도", 1},
        {"중요한 결정을 내릴 때?",
         "A: 논리와 객관성", "B: 감정과 공감", 2},
        {"친구가 고민을 이야기하면?",
         "A: 해결책을 제시", "B: 공감하며 들어줌", 2},
        {"여행 계획을 세울 때?",
         "A: 꼼꼼한 일정표", "B: 그때그때 결정", 3},
        {"과제 마감 스타일은?",
         "A: 미리미리 완료", "B: 마감 직전 집중", 3}
    };

    char name[50];
    int scores[4] = {0, 0, 0, 0};  // EI, SN, TF, JP
    char mbtiResult[5];

    // 이름 입력 (변수, scanf — 2차시)
    printf("🎮 MBTI 성격유형 테스트에 오신 걸 환영합니다!\n");
    printf("이름을 입력하세요: ");
    scanf("%s", name);
    printf("\n안녕하세요 %s님! 질문에 A 또는 B로 답해주세요.\n\n", name);

    // 질문 반복 (반복문 — 5차시)
    for (int i = 0; i < 8; i++) {
        char answer;
        printf("Q%d. %s\n", i + 1, quiz[i].question);
        printf("  %s\n", quiz[i].optionA);
        printf("  %s\n", quiz[i].optionB);
        printf("  선택 (A/B): ");
        scanf(" %c", &answer);

        // 점수 누적 (조건문 — 4차시)
        if (answer == 'A' || answer == 'a') {
            scores[quiz[i].dimension] += 1;
        } else {
            scores[quiz[i].dimension] -= 1;
        }
        printf("\n");
    }

    // MBTI 판정 및 결과 출력
    determineMBTI(scores, mbtiResult);
    printf("=============================\n");
    printf("🎉 %s님의 MBTI 유형: %s\n", name, mbtiResult);
    printf("=============================\n");

    return 0;
}

    🌉 C언어 → 임베디드로의 연결¶

    여러분이 배운 C언어 기초는 아두이노/ESP32 프로그래밍의 그대로의 기반입니다.

    flowchart LR subgraph 우리가_배운_것["🎓 우리가 배운 것"] A["변수"] B["조건문"] C["반복문"] D["함수"] end subgraph 임베디드_활용["🤖 임베디드 활용"] E["센서값 저장"] F["온도 높으면 팬 ON"] G["0.5초마다 센서 읽기"] H["LED_켜기( )"] end A --> E B --> F C --> G D --> H

    다음 단계에서는 이 지식으로 실제 하드웨어를 제어하게 됩니다! 🚀

    ✅ 점검하기¶

    1. MBTI 게임에서 scores[quiz[i].dimension]이 하는 역할은 무엇인가요?

    정답 확인 `quiz[i].dimension`은 현재 질문이 어떤 MBTI 차원(0:EI, 1:SN, 2:TF, 3:JP)에 해당하는지를 나타냅니다. 이 값을 인덱스로 사용해 해당 차원의 점수 배열에 접근하고, A/B 선택에 따라 +1 또는 -1을 누적합니다.

    2. 이 프로그램에서 사용된 C언어 개념을 3가지 이상 나열해보세요.

    정답 확인 변수(name, scores), 배열(quiz[], scores[]), 구조체(Question), 조건문(if-else), 반복문(for), 함수(determineMBTI), printf/scanf 입출력 — 총 7가지 이상의 개념이 하나의 프로그램에 통합되어 있습니다!

    3. 아두이노에서 if (temperature > 30)은 우리가 배운 어떤 개념인가요?

    정답 확인 조건문(if문)입니다! 센서에서 읽은 온도값을 변수에 저장하고, 조건문으로 판단해서 동작을 결정하는 것은 MBTI 게임에서 답변에 따라 점수를 다르게 준 것과 같은 원리입니다.
