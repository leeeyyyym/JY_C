    함수의 기본 — 코드를 상자에 담기¶

    Part 3: 코드를 정리하자 — 함수

    🎯 이 장에서 배우는 것¶

    • 반환형, 함수 이름, 매개변수, return으로 구성된 C 함수의 구조를 설명할 수 있다
    • void 함수와 값을 반환하는 함수를 구분하고 각각 작성할 수 있다
    • MBTI 게임 코드를 함수 단위로 분리할 수 있다

    📚 핵심 개념¶

    개념 1: C 함수의 구조 — 자판기에 비유하기 🥤¶

    파이썬에서 def로 함수를 만들어본 적 있죠? C에서도 함수를 만들 수 있는데, 딱 하나 큰 차이가 있어요. 바로 "이 함수가 돌려주는 결과물의 타입"을 미리 선언해야 한다는 점이에요.

    함수를 자판기라고 생각해보세요.

    flowchart LR A["동전 투입구\n(매개변수)"] --> B["자판기 내부\n(함수 본문)"] B --> C["음료 배출구\n(return)"] style B fill:#ffeeba,stroke:#333
    • 투입구(매개변수): 자판기에 넣는 재료. int score 같은 것
    • 자판기 라벨(반환형): 이 자판기에서 나오는 건 "음료(int)"인지 "아무것도 안 나옴(void)"인지 미리 표시
    • 배출구(return): 결과물을 바깥으로 내보내는 장치

    C 함수의 기본 형태는 이렇습니다:

    반환형 함수이름(매개변수) {
    // 함수 본문
    return 결과값;
}

    파이썬과 비교하면 이해가 빨라요.

    flowchart TB subgraph Python P["def add(a, b):\n return a + b"] end subgraph C언어 Q["int add(int a, int b) {\n return a + b;\n}"] end

    C에서는 a, b의 타입(int)과 돌려주는 값의 타입(int)을 전부 명시해야 해요. 귀찮다고요? 그 대신 컴파일러가 실수를 미리 잡아줍니다! 😊

    개념 2: void 함수 vs 값을 반환하는 함수¶

    모든 자판기가 음료를 내놓는 건 아니에요. 안내 방송기처럼 그냥 뭔가를 수행만 하고 끝나는 것도 있죠.

    • int, char 등 반환형이 있는 함수: 결과값을 return으로 돌려줌
    • void 함수: 아무것도 돌려주지 않음. return을 생략하거나 return;만 씀
    // 값을 반환하는 함수
int add(int a, int b) {
    return a + b;
}

// void 함수 — 화면에 출력만 하고 끝
void sayHello(void) {
    printf("안녕하세요!\n");
}

    💡 기억 포인트: 함수를 만들 때 항상 스스로 물어보세요. "이 함수는 결과값을 돌려줘야 하나, 아니면 그냥 뭔가를 수행만 하면 되나?" 전자면 int/char 등, 후자면 void!

    🔨 따라하기¶

    지금까지 main 함수 안에 길~게 작성했던 MBTI 게임 코드를 함수로 분리해봅시다. 이 과정을 리팩토링이라고 해요.

    Step 1: 질문을 출력하고 답을 받는 함수¶

    질문을 보여주고 사용자 입력(1 또는 2)을 받아 돌려주는 함수입니다.

    int askQuestion(char *question, char *opt1, char *opt2) {
    int answer;
    printf("%s\n", question);
    printf("1) %s\n", opt1);
    printf("2) %s\n", opt2);
    printf("선택: ");
    scanf("%d", &answer);
    return answer;  // 1 또는 2를 돌려줌
}

    포인트: 사용자가 고른 번호를 return으로 돌려주니까 반환형이 int예요.

    Step 2: 점수를 계산하는 함수¶

    답변 번호를 받아서 점수를 누적하는 함수입니다.

    int calculateScore(int currentScore, int answer) {
    if (answer == 1) {
        return currentScore + 1;
    }
    return currentScore;
}

    Step 3: 결과를 판정하고 출력하는 함수¶

    점수를 받아서 유형을 화면에 출력만 합니다. 돌려줄 값이 없으니 void!

    void showResult(int eScore, int sScore) {
    char type[3];  // 2글자 + 널문자

    if (eScore >= 1) {
        type[0] = 'E';
    } else {
        type[0] = 'I';
    }

    if (sScore >= 1) {
        type[1] = 'S';
    } else {
        type[1] = 'N';
    }
    type[2] = '\0';

    printf("\n당신의 유형: %s\n", type);
}

    Step 4: main에서 조립하기¶

    이제 main은 함수들을 순서대로 호출하기만 하면 돼요. 깔끔하죠? ✨

    int main(void) {
    int answer, eScore = 0, sScore = 0;

    answer = askQuestion("모임에서 나는?", "여러 명과 어울린다", "소수와 깊게 대화한다");
    eScore = calculateScore(eScore, answer);

    answer = askQuestion("새로운 정보를 접하면?", "실용성부터 따진다", "가능성을 상상한다");
    sScore = calculateScore(sScore, answer);

    showResult(eScore, sScore);
    return 0;
}

    실행 결과: 

    모임에서 나는?
1) 여러 명과 어울린다
2) 소수와 깊게 대화한다
선택: 1
새로운 정보를 접하면?
1) 실용성부터 따진다
2) 가능성을 상상한다
선택: 2

당신의 유형: EN

    📝 전체 코드¶

    #include <stdio.h>

/* 질문 출력 & 답변 입력 */
int askQuestion(char *question, char *opt1, char *opt2) {
    int answer;
    printf("%s\n", question);
    printf("1) %s\n", opt1);
    printf("2) %s\n", opt2);
    printf("선택: ");
    scanf("%d", &answer);
    return answer;
}

/* 점수 계산 */
int calculateScore(int currentScore, int answer) {
    if (answer == 1) {
        return currentScore + 1;
    }
    return currentScore;
}

/* 결과 출력 (void — 반환값 없음) */
void showResult(int eScore, int sScore) {
    char type[3];

    if (eScore >= 1) {
        type[0] = 'E';
    } else {
        type[0] = 'I';
    }

    if (sScore >= 1) {
        type[1] = 'S';
    } else {
        type[1] = 'N';
    }
    type[2] = '\0';

    printf("\n당신의 유형: %s\n", type);
}

int main(void) {
    int answer, eScore = 0, sScore = 0;

    answer = askQuestion("모임에서 나는?",
                         "여러 명과 어울린다",
                         "소수와 깊게 대화한다");
    eScore = calculateScore(eScore, answer);

    answer = askQuestion("새로운 정보를 접하면?",
                         "실용성부터 따진다",
                         "가능성을 상상한다");
    sScore = calculateScore(sScore, answer);

    showResult(eScore, sScore);
    return 0;
}

    ⚠️ 주의할 점¶

    1. 함수는 호출되기 전에 선언되어야 해요. 위 코드처럼 main 위에 함수를 작성하거나, 맨 위에 함수 프로토타입(예: int askQuestion(char*, char*, char*);)을 적어야 합니다. 순서를 바꾸면 컴파일 에러가 나요!

    2. 반환형과 return 값의 타입이 일치해야 해요. int로 선언한 함수에서 문자열을 return하면 에러입니다. 자판기 라벨에 "음료"라고 써놓고 빵을 내보내면 안 되는 것처럼요 🍞❌

    ✅ 점검하기¶

    1. C 함수에서 반환형이 void인 함수의 특징은 무엇인가요?

    정답 확인 값을 돌려주지 않는 함수입니다. `return` 문을 생략하거나 `return;`만 쓸 수 있고, 호출할 때 `변수 = 함수();` 형태로 결과를 받을 수 없습니다.

    2. 파이썬 def add(a, b): return a + b를 C로 바꾸면 어떻게 되나요?

    정답 확인 
    int add(int a, int b) {
    return a + b;
}
    매개변수 `a`, `b`의 타입과 반환형 `int`를 명시해야 합니다.

    3. 함수를 분리하면 얻는 가장 큰 장점 두 가지는?

    정답 확인 **가독성** — `main`이 짧아져서 전체 흐름이 한눈에 보입니다. **재사용성** — 같은 함수를 여러 곳에서 반복 호출할 수 있습니다.
