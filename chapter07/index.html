    배열 — 질문 목록을 한곳에 저장하기¶

    Part 4: 데이터를 묶어서 관리하자 — 배열과 구조체

    🎯 이 장에서 배우는 것¶

    • 배열의 개념을 이해하고 int, char 배열을 선언·초기화할 수 있다
    • 배열 인덱스(0부터 시작)와 반복문을 결합해 MBTI 질문·점수를 처리할 수 있다

    📚 핵심 개념¶

    개념 1: 배열이란?¶

    비유로 시작 🗄️

    지금까지 질문 하나마다 변수를 하나씩 만들었죠? 질문이 12개면 변수도 12개… 이건 서랍장 없이 물건을 바닥에 늘어놓는 것과 같아요. 배열은 "같은 크기의 서랍이 일렬로 붙어 있는 정리함"입니다. 번호표(인덱스)만 알면 원하는 서랍을 바로 열 수 있어요.

    정확한 정의

    배열(array)은 같은 자료형의 데이터를 연속된 메모리 공간에 고정된 개수만큼 저장하는 구조입니다.

    int scores[4];          // int 4칸짜리 배열 선언
int scores[4] = {0, 0, 0, 0};  // 선언 + 초기화

    파이썬과 다른 점 🐍➡️🔧

    • 파이썬 리스트: 크기 자유, 여러 자료형 섞기 가능 → [1, "hello", 3.14]
    • C 배열: 크기 고정, 한 가지 자료형만 → int scores[4]
    flowchart LR subgraph "파이썬 리스트" A["1"] --- B["'hello'"] --- C["3.14"] end subgraph "C 배열 int scores[4]" D["scores[0]\n0"] --- E["scores[1]\n0"] --- F["scores[2]\n0"] --- G["scores[3]\n0"] end

    💡 인덱스는 0부터 시작! 4칸 배열이면 [0], [1], [2], [3] — 파이썬과 같아요.

    개념 2: 문자열 = char 배열¶

    C에는 파이썬의 str 타입이 없습니다. 문자열은 char 배열 + 맨 끝 '\0'(널 문자)로 표현해요.

    char name[] = "Hello";
// 실제 메모리: 'H' 'e' 'l' 'l' 'o' '\0'  → 총 6칸

    여러 문자열을 묶으려면 2차원 char 배열 또는 문자열 포인터 배열을 쓰는데, 지금은 간단한 포인터 배열 형태를 사용합니다.

    const char *questions[3] = {
    "나는 사람 만나는 게 좋다",
    "나는 혼자 있는 게 편하다",
    "나는 계획을 세우는 편이다"
};

    questions[0]은 첫 번째 문자열, questions[2]는 세 번째 문자열을 가리킵니다.

    🔨 따라하기¶

    MBTI 질문 4개를 배열에 저장하고, 반복문으로 출력·입력·점수 집계까지 해봅시다!

    Step 1: 질문과 점수 배열 준비하기¶

    #include <stdio.h>

int main(void) {
    // 질문 배열 (4개)
    const char *questions[4] = {
        "모임에서 먼저 말을 거는 편이다",       // E/I
        "구체적 사실이 아이디어보다 중요하다",   // S/N
        "결정할 때 논리를 감정보다 우선한다",    // T/F
        "계획 없이 행동하면 불안하다"            // J/P
    };

    // 각 질문에 대응하는 점수 저장용 배열
    int scores[4] = {0, 0, 0, 0};

    return 0;
}

    배열 크기 4, 인덱스 0~3 — 딱 질문 수와 맞죠!

    Step 2: 반복문으로 질문 출력 & 답변 입력¶

    for문의 카운터 i가 곧 배열 인덱스가 됩니다.

        int answer;

    for (int i = 0; i < 4; i++) {
        printf("\nQ%d. %s\n", i + 1, questions[i]);
        printf("(1: 매우 아니다 ~ 5: 매우 그렇다): ");
        scanf("%d", &answer);
        scores[i] = answer;   // i번째 점수 저장
    }

    실행 결과 (사용자가 3, 4, 2, 5를 입력한 경우):

    Q1. 모임에서 먼저 말을 거는 편이다
(1: 매우 아니다 ~ 5: 매우 그렇다): 3

Q2. 구체적 사실이 아이디어보다 중요하다
(1: 매우 아니다 ~ 5: 매우 그렇다): 4

Q3. 결정할 때 논리를 감정보다 우선한다
(1: 매우 아니다 ~ 5: 매우 그렇다): 2

Q4. 계획 없이 행동하면 불안하다
(1: 매우 아니다 ~ 5: 매우 그렇다): 5

    Step 3: 결과 판정 & 출력¶

    점수 3 이상이면 앞 유형, 미만이면 뒤 유형으로 판정합니다.

        // 유형 문자 배열: 앞 글자 / 뒤 글자
    char front[4] = {'E', 'S', 'T', 'J'};
    char back[4]  = {'I', 'N', 'F', 'P'};
    char result[5];  // 4글자 + '\0'

    for (int i = 0; i < 4; i++) {
        result[i] = (scores[i] >= 3) ? front[i] : back[i];
    }
    result[4] = '\0';  // 문자열 끝 표시

    printf("\n🎉 당신의 MBTI: %s\n", result);

    실행 결과 (3, 4, 2, 5 입력 기준):

    🎉 당신의 MBTI: ESFJ

    scores가 {3, 4, 2, 5}이므로 → E(3≥3), S(4≥3), F(2<3), J(5≥3) → ESFJ

    📝 전체 코드¶

    #include <stdio.h>

int main(void) {
    const char *questions[4] = {
        "모임에서 먼저 말을 거는 편이다",
        "구체적 사실이 아이디어보다 중요하다",
        "결정할 때 논리를 감정보다 우선한다",
        "계획 없이 행동하면 불안하다"
    };

    int scores[4] = {0, 0, 0, 0};
    char front[4] = {'E', 'S', 'T', 'J'};
    char back[4]  = {'I', 'N', 'F', 'P'};
    char result[5];
    int answer;

    printf("=== MBTI 간이 테스트 ===\n");

    for (int i = 0; i < 4; i++) {
        printf("\nQ%d. %s\n", i + 1, questions[i]);
        printf("(1: 매우 아니다 ~ 5: 매우 그렇다): ");
        scanf("%d", &answer);
        scores[i] = answer;
    }

    for (int i = 0; i < 4; i++) {
        result[i] = (scores[i] >= 3) ? front[i] : back[i];
    }
    result[4] = '\0';

    printf("\n🎉 당신의 MBTI: %s\n", result);

    return 0;
}

    ⚠️ 주의할 점¶

    1. 배열 범위를 넘기면 큰일! 🚨

    int scores[4]에서 scores[4]에 접근하면 존재하지 않는 5번째 칸을 건드리는 것입니다. C는 파이썬처럼 친절한 에러를 안 줍니다 — 그냥 엉뚱한 메모리를 건드려서 프로그램이 이상하게 동작하거나 멈춥니다. 항상 인덱스 < 배열 크기인지 확인하세요.

    2. 문자열 끝에 '\0'을 잊지 마세요!

    result 배열을 printf("%s", result)로 출력할 때, C는 '\0'을 만날 때까지 읽습니다. 널 문자를 빼먹으면 쓰레기 값이 함께 출력됩니다.

    ✅ 점검하기¶

    1. int arr[5] = {10, 20, 30, 40, 50};에서 arr[3]의 값은?

    정답 확인 **40**입니다. 인덱스가 0부터 시작하므로 `arr[0]=10, arr[1]=20, arr[2]=30, arr[3]=40`입니다.

    2. C 배열과 파이썬 리스트의 가장 큰 차이 2가지는?

    정답 확인 - C 배열은 **크기가 고정**이고, 파이썬 리스트는 자유롭게 늘어남 - C 배열은 **같은 자료형만** 담을 수 있고, 파이썬 리스트는 여러 자료형을 섞을 수 있음

    3. char name[5] = "Hello";는 왜 문제가 될까요?

    정답 확인 "Hello"는 5글자이지만 끝에 `'\0'`이 필요하므로 **총 6칸**이 필요합니다. 5칸 배열에는 널 문자가 들어갈 자리가 없어서 문자열 처리 시 오류가 발생할 수 있습니다. `char name[6] = "Hello";` 또는 `char name[] = "Hello";`로 써야 합니다.
